Skill do Claude Code

Você constrói a base do seu OS agêntico

Um treinador particular que faz 2 ou 3 perguntas em português claro e constrói, camada por camada, os arquivos e pastas reais do seu próprio sistema operacional agêntico. Você não precisa saber programar — a skill faz o trabalho técnico, você só decide.

Começar o guia Ver no GitHub
O que é

Um OS agêntico é, na maior parte, encanamento

O modelo de IA é os 20% baratos. Você não consegue conversar com os seus dados se os bastidores estão uma bagunça — por isso a skill arruma os bastidores primeiro, e só depois empilha capacidade em cima.

🗣️ Fala como gente

Nunca soa como manual. Sem jargão — quando uma palavra técnica é inevitável, ganha uma frase curta e uma analogia do dia a dia. Assume que você nunca abriu um terminal.

🧱 Constrói de verdade

Não é conversa: a cada resposta sua, ela cria os arquivos e pastas reais na sua pasta, explicando o que fez e por quê.

🔒 Protege o sensível

Se você marca um campo como privado, ela nunca escreve aquele valor na pasta — guarda uma referência que não te identifica.

Como funciona

Seis camadas, construídas de baixo para cima

A Identidade é a fundação, o Substrato (os bastidores) é a maior camada, e os Agentes ficam no topo — só depois que tudo abaixo deles está firme.

1 · Identidade→ 2 · Substrato→ 3 · Regras & Hooks→ 4 · Skills→ 5 · Ferramentas→ 6 · Agentes

❓ Pergunta

Faz 2 ou 3 perguntas simples sobre a camada atual da vez, depois para e espera a sua resposta.

🏗️ Constrói

Cria o arquivo ou pasta de verdade daquela camada quando você responde, sob medida para o seu objetivo.

💾 Persiste

Grava a decisão e o seu lugar em memory.md, para nada se perder entre sessões — e pode auditar tudo a qualquer momento com OS-AUDIT.md.

Pré-requisitos

É só isso que você precisa

Sem dependências, sem chaves de API, sem etapa de build.

Claude Code

Instalado na sua máquina.

# verifique a instalação
claude --version

A skill copiada

Coloque a pasta os-coach dentro das suas skills do Claude Code.

# instalar
cp -r os-coach ~/.claude/skills/

Uma pasta qualquer

Rode dentro de qualquer pasta que você queira transformar num OS — ela vira o próprio OS.

# dentro da pasta
mkdir meu-os && cd meu-os
Guia de uso · passo a passo

Do zero ao seu primeiro OS agêntico

Você dá sempre um pequeno passo por vez. O treinador pergunta, constrói, persiste, e te aponta a próxima camada.

1

Comece com o seu objetivo

Diga em português claro aonde você quer chegar. A skill confirma o objetivo e prepara a pasta.

/os-coach start Eu vivo perdendo prazos de cliente e quero nunca mais atrasar uma entrega  # inicia o OS na pasta atual
2

Responda as perguntas de cada camada

2 ou 3 perguntas simples por vez — para quem isto é, o que ela deve sempre fazer, o que nunca deve fazer. Ela escreve o arquivo de Identidade (CLAUDE.md) com as suas próprias palavras.

# ela escreve algo como
## Recusas inegociáveis (nunca)
- Eu nunca mando mensagem para um cliente sem você ler e aprovar antes.
3

Avance camada por camada

Vá para a próxima camada não terminada. Ela treina o Substrato, as Regras, as Skills, as Ferramentas e os Agentes, sempre lendo e escrevendo no mesmo memory.md.

/os-coach next  # vai para a próxima camada e treina ela
4

Veja onde você está

A qualquer momento, confira o mapa de progresso a partir da memória, ou pule direto para uma camada específica.

/os-coach status                 # mapa de progresso
/os-coach layer skills           # pula para a camada de Skills
5

Audite quando quiser

Ela pontua todas as seis camadas em relação ao seu objetivo, entrega os três próximos movimentos de maior alavancagem, e escreve o relatório em OS-AUDIT.md.

/os-coach audit  # boletim + próximos passos, em ordem de prioridade

Novidades · out/2026

O que a skill passou a cobrar

As seis camadas continuam as mesmas. O que mudou foi o que conta como "camada firme" no treino e na auditoria.

Identidade
Portátil e que aprendeUm AGENTS.md para o Codex e outros agentes entenderem o mesmo OS, e as seções ## Self-learning e ## Lessons: cada correção vira regra de uma linha.
Substrato
Contexto que atravessa sessõescontext/current-state.md, tasks/current.md e handoffs/latest.md: o OS retoma de onde parou sem você explicar tudo de novo.
Regras
Níveis de permissão e registro de falhasN0 só conversa até N4 age sozinho; um FALHAS.md com uma linha por erro, e o erro que repete vira regra fixa ou gancho.
Skills · Tools · Agentes
Prateleira limpa e delegação com critérioGatilho claro em cada skill, nível de permissão em cada conexão, modelo escolhido num arquivo só, e um segundo revisor antes do que é importante sair.
Opcional
Execução longaDepois dos Agentes, a skill pode montar uma pasta longrun/ com objetivo e prova de pronto para o OS trabalhar horas sozinho. Kit Execução Longa · Curso completo (AIOS)
Roadmap

Você constrói a base. Ele roda o agente.

O OS Coach não executa tarefas por você no dia a dia — ele estrutura a fundação sobre a qual um agente confiável consegue rodar.

Hoje
OS Coach constrói a baseIdentidade, Substrato, Regras, Skills, Ferramentas e Agentes — arquitetura, lógica e estrutura, sem executar nada por conta própria.
Depois
Uma plataforma de execução roda o agenteUma vez que a base está firme, uma plataforma como o OpenClaw pega o que foi preparado aqui e coloca para trabalhar: mensagens, automações, ferramentas e dashboards.
Sempre
Auditoria contínuaPeça uma avaliação a qualquer momento e o OS Coach pontua as seis camadas em relação ao seu objetivo, realimentando os próximos movimentos.
