What it is

An agentic OS is mostly plumbing

The AI model is the cheap 20%. You can’t talk to your data if the plumbing is a mess — that’s why the skill sorts out the plumbing first, then builds capabilities on top.

🗣️ Speak naturally

Never sounds like a manual. No jargon — when a technical term is unavoidable, it gets a short sentence and an everyday analogy. Assumes you’ve never opened a terminal.

🧱 Build for real

It’s not a conversation: with each answer you give, it creates the actual files and folders in your folder, explaining what it did and why.

🔒 Protect sensitive information

If you mark a field as private, it never writes that value to the folder — it stores a reference that doesn’t identify you.

How it works

Six layers, built from the bottom up

Identity is the foundation, Substrate (the behind-the-scenes layer) is the largest layer, and Agents sit at the top — only after everything below them is solid.

1 · Identity→ 2 · Substrate→ 3 · Rules & Hooks→ 4 · Skills→ 5 · Tools→ 6 · Agents

❓ Ask

Asks 2 or 3 simple questions about the current layer, then stops and waits for your answer.

🏗️ Build

Creates the actual file or folder for that layer when you answer, tailored to your goal.

💾 Persist

Saves the decision and your place in memory.md, so nothing gets lost between sessions — and you can audit everything anytime with OS-AUDIT.md.

User guide · step by step

From zero to your first agentic OS

You always take one small step at a time. The coach asks, builds, persists, and points you to the next layer.

1

Start with your goal

Clearly state in Portuguese where you want to get to. The skill confirms the goal and prepares the folder.

/os-coach start Eu vivo perdendo prazos de cliente e quero nunca mais atrasar uma entrega  # starts the OS in the current folder
2

Answer the questions for each layer

2 or 3 simple questions at a time — who this is for, what it should always do, what it should never do. It writes the Identity file (CLAUDE.md) in your own words.

# it writes something like
## Recusas inegociáveis (nunca)
- Eu nunca mando mensagem para um cliente sem você ler e aprovar antes.
3

Work through one layer at a time

Go to the next unfinished layer. It trains Substrate, Rules, Skills, Tools, and Agents, always reading from and writing to the same memory.md.

/os-coach next  # moves to the next layer and trains it
4

See where you are

At any time, check the progress map from memory, or jump straight to a specific layer.

/os-coach status                 # progress map
/os-coach layer skills           # skips to the Skills layer
5

Audit whenever you want

It scores all six layers against your goal, gives you the three highest-leverage next moves, and writes the report to OS-AUDIT.md.

/os-coach audit  # bulletin + next steps, in priority order

What's new · Oct 2026

What the skill now checks for

The six layers are the same. What changed is what counts as a "solid layer" in coaching and in the audit.

Identity
Portable and self-learningAn AGENTS.md so Codex and other agents understand the same OS, plus ## Self-learning and ## Lessons sections: every correction becomes a one-line rule.
Substrate
Context that survives sessionscontext/current-state.md, tasks/current.md and handoffs/latest.md: the OS resumes where it stopped without you explaining everything again.
Rules
Permission levels and a failure logFrom N0 (only talks) to N4 (acts alone); a FALHAS.md with one line per mistake, and a mistake that repeats becomes a fixed rule or a hook.
Skills · Tools · Agents
A clean shelf and careful delegationA clear trigger on each skill, a permission level on each connection, the model chosen in a single file, and a second reviewer before anything important goes out.
Optional
Long runsAfter Agents, the skill can set up a longrun/ folder with a goal and proof of done so the OS can work alone for hours. Long-run kit · Full course (AIOS)
